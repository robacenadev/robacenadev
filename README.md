## 📌 Projetos em Destaque

### 🌊 Growth Ocean — CRM & ERP para Agência de Marketing Digital

> Sistema web de gestão interna completo, construído do zero para a **Easy Drop**, agência de marketing digital. Em desenvolvimento ativo desde Mar/2026.

O sistema centraliza toda a operação da empresa — do primeiro contato com o cliente até a entrega final — em uma única plataforma integrada.

**Stack:**
`Django 5.1` `Django REST Framework` `PostgreSQL 16` `Docker` `Railway`

**O que o sistema faz:**

| Módulo | Descrição |
|--------|-----------|
| 🔐 Autenticação | Login com controle de permissões por usuário |
| 👥 Clientes | Cadastro completo com histórico de serviços e pagamentos |
| 🔀 Pipeline de Captação | Funil visual estilo kanban — do lead ao cliente |
| 📋 Serviços | Catálogo com preços e categorias |
| 🔗 Cadastro Público | Link para o cliente se cadastrar sozinho (com honeypot anti-bot) |
| ✅ Kanban de Tarefas | Organização de projetos com prioridade, prazo e responsável |
| 💰 Financeiro | Controle de receitas, despesas e recorrências |
| 📝 Orçamentos | Propostas comerciais com link de aprovação online |
| 📄 Contratos PDF | Geração automática de contrato após aprovação do orçamento |
| 📅 Agenda | Calendário integrado com Google Calendar |
| 🌐 Site Institucional | Vitrine digital integrada ao sistema — leads do site → pipeline |
| 💳 Cobranças Automáticas | Integração com Asaas para boletos, PIX e links de pagamento |
| 📱 WhatsApp Integrado | Notificações automáticas para clientes |
| 📊 Portal do Cliente | Dashboard para o cliente acompanhar o projeto em tempo real |

### 🌐 Plataforma de Gestão de Custos Multi-Cloud

> Plataforma web corporativa para **consolidação, análise e gestão de custos** em ambientes AWS, Azure e Huawei Cloud.

Assumi o projeto após a saída do desenvolvedor anterior, atuando em toda a stack:

| Área | Atividades |
|------|-----------|
| **Backend** | Manutenção e evolução em Django, refatoração de código legado |
| **Automação** | Pipelines de ingestão de dados de billing via n8n |
| **Banco de Dados** | Estruturação e otimização de MySQL |
| **Frontend** | Dashboards com Chart.js, exportação de relatórios PDF |
| **Infra** | Docker Swarm + Traefik, multi-cliente com segregação de dados |

`Python` `Django` `MySQL` `n8n` `Docker Swarm` `Traefik` `JavaScript` `Chart.js`
